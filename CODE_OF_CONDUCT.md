# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolhedor e construtivo; assédio e comportamento excludente não são tolerados.

## Aplicação
Casos de comportamento abusivo, de assédio ou inaceitável podem ser reportados ao mantenedor [@felipecaninnovaes](https://github.com/felipecaninnovaes) pelo contato listado no perfil do GitHub (não use issues públicas). Todas as denúncias serão analisadas com confidencialidade.
